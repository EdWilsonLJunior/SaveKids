# Spacing

> Give elements room with empty space.

Space tokens maintain consistent spacing. They ensure sufficient **margins** between elements and provide necessary **padding** inside elements.

> *Examples: spacing token applied between two buttons; spacing tokens used as padding inside a button.*

## Spacing scale

Our spacing tokens are based on an **8 pixel base unit**. We provide different spacings to accommodate most use cases and screen sizes.

| Token | Value |
| --- | --- |
| `spacing-3xs` | 4 px |
| `spacing-2xs` | 8 px |
| `spacing-xs` | 16 px |
| `spacing-s` | 24 px |
| `spacing-m` | 32 px |
| `spacing-l` | 40 px |
| `spacing-xl` | 48 px |
| `spacing-2xl` | 56 px |
| `spacing-3xl` | 64 px |
| `spacing-4xl` | 72 px |
| `spacing-5xl` | 82 px |
| `spacing-6xl` | 96 px |
| `spacing-7xl` | 128 px |
| `spacing-8xl` | 176 px |

## In Figma

In order to use the spacing tokens in Figma, first apply an **Auto Layout** to your frame. The tokens can then be applied to the component — for example, as gutters and padding.

> *Example: applying a spacing token in Figma.*
