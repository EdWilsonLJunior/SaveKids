# Overview — Show more button

> Reveals more content progressively without navigating away from the page.

**Related sections:** [Guidelines](Guidelines%20-%20Show%20more%20button.md) · [Specs](Specs%20-%20Show%20more%20button.md) · [Button guidelines](Button%20guidelines.md)

## When to use

The show more button reveals additional content when clicked. It displays hidden content **without navigating away** from the current page, allowing users to access more information in a seamless and intuitive way.

> How many new items are revealed after each click is decided per composition.

## Variants

Buttons are available in different variants to support various background types and levels of visual emphasis.

### Background variants

| Variant | Use on |
| --- | --- |
| `onLite` | Light backgrounds |
| `onHeavy` | Dark or high-contrast backgrounds |
| `onPhoto` | Photographic or complex imagery backgrounds |

For guidance on when to use each background variant, refer to the Lite and Heavy section on the [Color](Introduction%20-%20Color.md) page.

### Emphasis levels

| Variant | Secondary | Tertiary |
| --- | --- | --- |
| `onLite` | ✅ | ✅ |
| `onHeavy` | ✅ | ✅ |
| `onPhoto` | ✅ | ❌ (accessibility/contrast) |

## Behavior

The show more button can be used multiple times on the same page. For example:

- The first click reveals 6 additional items.
- A second click reveals another 6 items.

The amount of content revealed per click can vary based on the specific use case.
