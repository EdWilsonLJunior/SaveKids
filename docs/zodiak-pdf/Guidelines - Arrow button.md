## Usage

### Arrow buttons vs. tertiary icon buttons

Arrow buttons and tertiary icon buttons serve **different purposes** in layout alignment. Tertiary icon buttons include padding, which can cause visual misalignment in certain designs — especially when placed next to text or other elements.

**Use an Arrow button when:**

- A large area, like an entire card, is clickable. The arrow button itself has a reduced clickable area compared to a tertiary icon button.
- The arrow needs to **visually align** with surrounding content.

| ✅ Do | ❌ Don't |
| --- | --- |
| Use an arrow button when the entire card is interactive and the arrow should align with adjacent elements like text. | Don't use the tertiary icon button if the card is fully clickable and the arrow needs to be aligned with other content. |
| Ensure the arrow button is aligned with any text or other elements. | Don't use the tertiary icon button when the arrow needs to align with the text. |
