A tooltip provides brief, contextual information about a UI element when the user hovers over, taps, or focuses on it. It reduces clutter and offers guidance without overwhelming the interface.

Light mode

Dark mode

1. Container

2. Text label: The message inside the tooltip.

3. Pointer: A triangular indicator that links the tooltip to its trigger, always pointing toward the

referenced element and positioned above or below the tooltip.
