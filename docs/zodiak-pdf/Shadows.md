# Shadows

> Create depth and make elements stand out.

Shadows add emphasis by making elements appear elevated. We provide a **single shadow option**.

| Token | Value |
| --- | --- |
| `shadow-capgemini` | `4px 0 70px 3px rgba(0, 0, 0, 0.03)` |

## Usage

Shadows should be used **sparingly** and only when essential — such as when no other design solution achieves the desired clarity. Capgemini emphasizes a **flat design approach**, discouraging unnecessary shadows to maintain a clean, minimalist aesthetic.

| ❌ Don't |
| --- |
| Don't use shadows on modals. |
