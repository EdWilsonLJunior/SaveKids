# Avatar

Represent a user, group, or brand.

> **Status:** Healthy · [Open in Figma](#)

An avatar visually represents a user, group, or entity. It uses a profile image, icon, or initials to create a recognizable identity. Avatars help personalize the experience, improve recognition, and make it easier to identify individuals or accounts in contexts such as messaging, notifications, and user profiles.

## Anatomy

| # | Element | Notes |
|---|---|---|
| 1 | Avatar container | Represents the user or company with an image or initials |
| 2 | Status indicator (optional) | Displays the current status of the user |

> Light mode and dark mode variants available in Figma.

## Variants

The avatar is available in three variants.

**Photographic** — Displays a user's profile image. Automatically switches to initials if the image cannot load.

**Initials** — Shows the first and last name initials of the account when no profile image is provided. Limit to two characters for clarity and use the provided background colors.

**Brand** — Used to represent an organization or group rather than an individual.
