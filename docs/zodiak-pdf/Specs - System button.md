# Specs — System button

> Trigger actions in complex systems or digital products.

**Related sections:** [Overview](Overview%20-%20System%20button.md) · [Button guidelines](Button%20guidelines.md)

## States

All system button variants support **five distinct interaction states**: `default`, `hover`, `pressed`, `focus`, and `disabled`. See [Button guidelines](Button%20guidelines.md) for details on each state.

## Size

System buttons are available in **two sizes**, with medium being the most commonly used. The button's width adapts to the label content.

| Size | Usage | Height | Target height | Max width |
| --- | --- | --- | --- | --- |
| **Small** | Compact layouts where space is limited. | 38 px | 38 px | 312 px |
| **Medium** | Most common size. | 48 px | 48 px | 312 px |
