# Size — Typography

> Use a t-shirt size scale to apply consistent visual hierarchy across components and pages.

**Related sections:** [Overview](Overview%20-%20Typography.md) · [Color](Color%20-%20Typography.md) · [Usage](Usage%20-%20Typography.md)

## Why t-shirt sizes?

Zodiak provides a range of typography sizes to support a clear visual hierarchy. Instead of assigning fixed sizes to semantic tags like `<h1>` or `<h2>`, we use **t-shirt sizing** (S, M, L, …) to define text styles.

Designers select the appropriate size based on **visual hierarchy and design context**, rather than semantic structure. For example, a headline on a landing page may use a larger size than a headline in a modal, even if both serve similar semantic roles.

> Each size is available in **300 (Light)** and **400 (Regular)** weight. The 400 weight also has an italic variant.

## Headings

| Token | Font size | Line height | Letter spacing |
| --- | --- | --- | --- |
| `heading-6xl-300` | 128 px | 134 px | -1.5 px |
| `heading-5xl-300` | 96 px | 108 px | -0.8 px |
| `heading-4xl-300` | 72 px | 84 px | -1.2 px |
| `heading-3xl-300` | 56 px | 68 px | -0.6 px |
| `heading-2xl-300` | 48 px | 58 px | -0.3 px |
| `heading-xl-300` | 40 px | 50 px | -0.2 px |
| `heading-l-300` | 32 px | 40 px | 0 px |
| `heading-m-300` | 24 px | 32 px | 0.3 px |
| `heading-s-300` | 18 px | 26 px | 0.2 px |
| `heading-xs-300` | 16 px | 21 px | 0.3 px |
| `heading-2xs-300` | 14 px | 18 px | 1.4 % |

> Each `heading-*-300` token has a corresponding `heading-*-400` (Regular) variant. The 400 variant uses the same metrics; only the weight changes.

## Body text

| Token | Font size | Line height | Letter spacing |
| --- | --- | --- | --- |
| `body-xl-400` | 24 px | 36 px | 1.2 % |
| `body-l-400` | 18 px | 30 px | 1.2 % |
| `body-m-400` | 16 px | 26 px | 1.5 % |
| `body-s-400` | 14 px | 21 px | 2.2 % |
| `body-xs-400` | 12 px | 18 px | 2.5 % |

> Body text is also available in **300 (Light)** and **400 Italic** variants when emphasis is needed (italics for decorative purposes only — see [Overview](Overview%20-%20Typography.md)).
