# Overview — System warning button

> Signal high-risk actions within complex systems.

**Related sections:** [Specs (primary)](Specs%20-%20System%20warning%20button%20primary.md) · [Specs (secondary)](Specs%20-%20System%20warning%20button%20Secondary.md)

System buttons are designed for **building complex systems or digital products**. **Do not use them for regular web pages.**

Use a System warning button for actions that may have **serious consequences**, such as deleting data, canceling an account, or making irreversible changes. The warning button comes with a predefined warning icon which **should not be changed**. These buttons should always be followed by a **user confirmation** before completing the action.

## Variants

System warning buttons have a **primary** and **secondary** variant.
