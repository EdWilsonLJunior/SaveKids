# Notice

Provide brief, contextual feedback or updates to users.

Notice is a type of notification that provides brief feedback or updates to users. It is used to confirm actions, alert users to errors or changes, or deliver other contextual information. Depending on the variant it can be persistent or temporary.

Dark mode

6. Close icon (optional): Allows users to dismiss the notice.
