## Variants

The switch comes in three variants: without a label, right-side label and left-side label.

Switches with hidden labels should only be used in contexts that make it clear what the user is selecting. It should be visually tied to a recognizable element, such as selecting a theme preview or picking a color swatch.

Always ensure accessible labeling is provided using aria-label or aria-labelledby to support screen readers.

## Behavior

A switch is a toggle control that changes a setting between two states: on and off. When the switch is turned on, the associated feature becomes active; when turned off, the feature is disabled. The sliding button moves horizontally when clicked and changes its icon to indicate the current state.
