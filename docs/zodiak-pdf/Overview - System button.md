# Overview — System button

> Trigger actions in complex systems or digital products.

**Related sections:** [Specs](Specs%20-%20System%20button.md) · [Button guidelines](Button%20guidelines.md)

## When to use

System buttons are designed for building **complex systems or digital products**. Do not use them for regular web pages.

## Variants

System buttons have two variants:

| Variant | When to use |
| --- | --- |
| **Primary** | For the main or most important action in the system context. |
| **Secondary** | For supporting actions that are important but not the primary focus. |
