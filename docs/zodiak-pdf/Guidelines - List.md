## Usage

When to use:

To make content clear, scannable, and easy to follow.

To highlight key points.

To break up dense content.

To show steps, order, or hierarchy.

Bulleted lists should be used for collections where order doesn’t matter.

Numbered lists should be used for sequences, steps, ranking, or priority.

When not to use:

For complex or structured data, use a table instead.

Content

Keep items short and scannable.

Maintain parallel grammar and a consistent writing style.

Do

Use approximately similar text lengths.

Don't

Don't mix different text lengths.

SEO

Use proper HTML tags like <ol> and <ul> .
