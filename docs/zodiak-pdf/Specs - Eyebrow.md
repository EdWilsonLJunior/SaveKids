## Size

Eyebrows are available in two sizes: medium and small. Small is used on mobile viewports, while medium is applied on tablet and desktop.

| Eyebrow size | Viewport | Typography token | Dash thickness |
| ------------ | -------- | --------------- | -------------- |
| Medium | Desktop and tablet | heading-xs-300 | 1px |
| Small | Mobile | heading-2xs-300 | 1px |

## Character limit

The eyebrow is designed to never break on two rows.

| Size   | Max characters |     |     |     |
| ------ | -------------- | --- | --- | --- |
| Medium | ~ 30           |     |     |     |
| Small  | ~ 30           |     |     |     |

## Color

The eyebrow uses a single color for both the em-dash and the content.

| Color | Token |
| ----- | ----- |
| #171a22 | Text Primary |
| #f8fafc | Light Text |

## Don't / Do

**Don't:** Don't change the styling of the eyebrow. Use the default styling of the eyebrow.
