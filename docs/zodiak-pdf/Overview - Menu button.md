# Overview — Menu button

> Compactly open a navigation menu.

**Related sections:** [Guidelines](Guidelines%20-%20Menu%20button.md) · [Specs](Specs%20-%20Menu%20button.md)

## When to use

Menu buttons are ideal for **compact spaces**, like mobile layouts or dropdowns. They allow multiple actions to be grouped together without cluttering the screen.

## Anatomy

The menu button consists of a **label** and a **chevron icon**. When clicked, the chevron rotates 180 degrees to indicate the menu's expanded or collapsed state.

| # | Element | Description |
| --- | --- | --- |
| 1 | **Button label** | Describes what type of options will appear when the menu is opened. |
| 2 | **Chevron icon** | Indicates that the menu can be expanded or collapsed. Rotates 180° when toggled. |
| 3 | **Mini menu** | Appears when the menu button is clicked and displays a list of selectable options. |

## Variants

The menu button has **three variants**. Choose the one that best matches the importance of the actions in the menu.

| Variant | When to use |
| --- | --- |
| **Primary** | Used at most once per view or section to guide users toward the main action. |
| **Secondary** | For actions that are important, but not the main focus. |
| **Tertiary** | For less frequently used options, like settings. |
