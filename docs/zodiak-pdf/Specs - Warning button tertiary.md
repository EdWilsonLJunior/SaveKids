# Specs — Warning button (Tertiary)

> A low-emphasis text-only warning button used for inline destructive actions in lists, menus, or dense layouts.

**Related sections:** [Overview](Overview%20-%20Warning%20button.md) · [Guidelines](Guidelines%20-%20Warning%20button.md) · [Specs Primary](Specs%20-%20Warning%20button%20primary.md) · [Specs Secondary](Specs%20-%20Warning%20button%20secundary.md)

## States

The warning button supports the five standard interaction states.

## Color — Tertiary (text only, with underline)

| State | Underline / fg | Token |
| --- | --- | --- |
| Default | `#b3261e` | `action-warning-default` |
| Hover | `#8c1d18` | `action-warning-hover` |
| Focus | `#b3261e` + `#2e323a` ring | `action-warning-default` + `action-focus-onLite` |
| Pressed | `#601410` | `action-warning-pressed` |
| Disabled | `#a6acb5` | `action-disabled` |
