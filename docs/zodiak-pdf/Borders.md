# Borders

> Define boundaries and create visual separation between components.

## Styles

Borders come in **three different line weights** to provide different levels of emphasis. Most Zodiak components come with predefined borders (or none at all), which should be kept as they are to maintain design consistency.

| Token | Weight | Usage |
| --- | --- | --- |
| `border-thin` | 1 px | Default border for most components. |
| `border-medium` | 2 px | Mid-emphasis separators or focused states. |
| `border-thick` | 4 px | Strong emphasis or feature framing. |

> Refer to the original PDF for the visual weight comparison.

## Color

We use **low-contrast borders** to maintain a clean look.

| Token | Light mode | Dark mode |
| --- | --- | --- |
| `border-primary` | `#c7ccd3` | `#3c414a` |
| `border-secondary` | `#eff0f4` | `#2e323a` |

Refer to the [color documentation](Introduction%20-%20Color.md) for the complete list of colors.
