A button initiates an action or event when clicked. This can include submitting a form, navigating to a different page, downloading a file, or opening a pop-up window.

## Anatomy

The button exists **with and without an icon**.

1. **Container** — houses the content and helps represent the hierarchy and state of the button.
2. **Label** — informs what action the button does.
3. **Icon** *(optional)* — can be on the left or right side and supports the label with information.

## Variants

Buttons have three variants: **primary, secondary, and tertiary**. To guide users to the main action, use a clear button hierarchy. Each page should ideally have one primary button, and can include multiple secondary and tertiary buttons. This distinction helps users prioritize actions.

> The **tertiary variant without an icon** has an underline to ensure the button meets accessibility standards.

### Full-width button

**Full-width buttons** span the entire width of their container. These buttons offer high visibility and are easy to interact with, making them ideal for **mobile layouts and fixed-width panels**. Its label and icon may change upon interaction, but the button's width should always remain constant.

> *Example: a full-width button inside a modal.*
