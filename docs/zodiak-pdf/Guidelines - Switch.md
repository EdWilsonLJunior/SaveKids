Interaction

Switches must support both mouse and keyboard input to ensure accessibility and consistent behavior across devices.

Mouse

Users can activate a switch by clicking either the switch itself or its label.

Both the switch and label should respond to pointer events. When hovering over this region, the cursor must change to a pointer to indicate that the element is clickable.

Keyboard

Users should be able to navigate to the switch using the Tab key. Once focused, the switch can be toggled using the Spacebar.

The focus state appears when the switch is selected via keyboard, confirming its active state and supporting accessibility standards.
