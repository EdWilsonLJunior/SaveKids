# Radius

> Soften edges of components.

Radius tokens round the corners of images, buttons, and other elements. We use radii **sparingly** to maintain a clean design. Each Zodiak component comes with **predefined radii** that should be preserved for consistency.

> *Example: large radius token applied to a button.*

## Style

There are **four radius tokens**.

| Token | Value | Typical use |
| --- | --- | --- |
| `radius-xs` | 4 px | Subtle rounding (inputs, small chips). |
| `radius-s` | 16 px | Standard surfaces (cards, modals). |
| `radius-m` | 32 px | Larger surfaces or feature framing. |
| `radius-l` | 999 px | Pill / fully-rounded (avatars, pill buttons). |
