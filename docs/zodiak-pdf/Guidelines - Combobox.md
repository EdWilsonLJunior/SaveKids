# Combobox

Select one value from a list of options using search.

## Usage

Use a combobox when users need to select one option, but the list of possible values is long, dynamic, or not fully predefined.

When not to use

When the list of options is short and easy to scan (use a dropdown instead).

When multiple selections are required (use a multiselect).

Content

Label text

Label text informs users what to expect in the list of options.

Keep the label text short and concise by limiting it to a single line of text.

Do not remove label text in favor of using placeholder text in the combobox field. Labels are always strongly encouraged to be included when possible.

Helper text

Helper text provides relevant guidance to help users make the correct selection from a combobox menu. It appears below the label and is visible when the combobox field is focused.

Use helper text to:

Clarify the purpose of the combobox or explain selection criteria.

Provide formatting rules or additional context for the choices.

Offer feedback or instructions to ensure accurate input.

Keep it concise, ideally one line.

Use sentence-style capitalization and full sentences with punctuation.

Avoid overwhelming users with too much detail; helper text should support, not distract.

## Guidelines

Types of helper text messages

Informational: Offers hints or helpful details. Example: “Select your department from the list.”

Warning: Alerts users to potential issues. Example: “Changing this selection may affect your settings.”

Error: Explains why a choice is invalid and how to fix it. Error messages replace helper text until resolved. Example: “Please select at least one option.”

Success: Confirms a valid action. Example: “Selection saved successfully.”

Search field placeholder text Use clear and concise placeholder text in the combobox field to indicate how to interact with the combobox. For example, “Search” is commonly used as placeholder text.

Combobox options text

Combobox option text should be brief, accurate, and not descriptive.

Never use decorative images or icons within a combobox.

We recommend presenting the options in alphabetical order.
