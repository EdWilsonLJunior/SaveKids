# Overview — Icon button

> Trigger an action using a recognizable symbol.

An icon button triggers an action or event when clicked, such as navigating to another page or executing a specific function (e.g. downloading a file or sharing content via social media). It provides an interactive element for users to engage with the site and quick visual cues for actions, improving navigation and saving space.

Icon buttons are particularly useful when there is **limited space**, or for actions users perform frequently. The icon must be **universally recognizable** and clearly convey the action.

## Anatomy

1. **Container** — houses the icon and provides a visual indication of hierarchy.
2. **Icon** — visual representation of the button's functionality.

## Variants

To guide users to the main action, use a **clear button hierarchy**. Each page should ideally have one primary button and can include multiple secondary and tertiary buttons. This distinction helps users prioritize actions. See the [Button guidelines](Button%20guidelines.md) for more on hierarchy.

The `onPhoto` variant of the secondary button uses the `action-primary-onPhoto` fill to ensure sufficient contrast when placed over images.
