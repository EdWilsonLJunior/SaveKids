# Overview — Arrow button

> Indicate clickable areas used for navigation.

An arrow button is placed on a clickable area to indicate that the element is interactive. Use the arrow button on components that link to other pages or subpages.

**Use the arrow button when:**

- A larger area is clickable (e.g. cards).
- Precise alignment of the icon and text is important.

## Anatomy

> Available for both **light mode** and **dark mode**.

1. **Container** — transparent container that houses the arrow icon.
2. **Arrow icon**.

## Behavior

The arrow button **lengthens slightly** when hovered or pressed. This gives the user a visual cue that it is an interactive element.
