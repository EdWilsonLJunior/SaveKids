# Text input

Enter and edit text through an input area.

Content

Label

Labels clearly communicate what input is expected from the user. Every text field must have a label that is always visible and aligned with the input container. Labels should be short, descriptive, and written in sentence-style capitalization, except for product names and proper nouns. Avoid using colons at the end of label text. A well-crafted label improves clarity and accessibility.

Placeholder text

Provides hints or examples of what to enter. Placeholder text disappears after the user begins entering data into the input. As such, it should not be used as a replacement for a persistent label nor should it contain crucial information. Use sentence-style capitalization, and in most cases, write the text as a direct statement without punctuation. Placeholder text should only be added when necessary.

Helper text

Helper text provides additional guidance to help users complete a field correctly. It can explain formatting requirements, clarify intent, or offer feedback. Helper text should be concise and typically fit on a single line. It may appear persistently or only when the field is focused.

Use sentence-style capitalization and write in full sentences with punctuation. Avoid overloading the field with information. Helper text should support, not distract.

Helper text can convey four different types of messages:

Informational: Provides a hint or helpful information, such as formatting rules. Example: “Use a work email address.”

Warning: Alerts users to potential issues that may affect submission or future use. Example:
“Passwords don’t match.”

Error: Explains why input is invalid and how to fix it. Error messages are displayed below the input line, replacing helper text until fixed. Example: “Email format is invalid.”

Success: Confirms that the action was completed. Example: “Your changes has been saved.”

Required fields

To reduce cognitive load, mark only the less common fields in the form.

If most fields are required, mark only the optional fields with (optional).

If most fields are optional, mark only the required fields with an asterisk (*). At the top of the form, include a note explaining that asterisks indicate required fields.

When most fields are optional, only the required fields are marked.
