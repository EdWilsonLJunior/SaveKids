# Author

Display the writer(s) of an article.

Specs

Guidelines

## Usage

Besides being used in articles, the Author component can also be used in article teasers (e.g. in a news listing). A mix of different authors is allowed.

Content

Author Data

Including the author's name helps establish credibility and trust.

Use full names and ensure consistency across articles.

If multiple contributors are involved, use the multi-author component.

Author data can be used in structured schema markup (e.g., Article or BlogPosting schema), which improves how content is indexed and displayed in search results.

Don't

Do

Do not have inconsistent author information.

Ensure each author component in the list includes the same information.

Do

Don't

Use a clear picture for the avatar.

Don't use vague imagery for the avatar.

Publication date

The date of publication signals content freshness, which is important for time-sensitive topics to help users assess relevance.

We recommend the following format for displaying the dates: Month + Day, Year. E.g. January 31, 2025.
