# Radio

Choose a single option from a set.

Radio buttons allow the user to select a single option from a set. When a new item is selected, the previous choice is automatically deselected. They are often used in polls and choosing language preferences.

Unlike checkboxes, which allow multiple choices, radio buttons only allow a single option to be selected.

Anatomy

1. Radio button: Displays the status of the radio button.

2. Label: Describes the option associated with the radio button.

## Variants

Radio buttons include a label that describes each option clearly. In specific use cases, labels may be visually hidden.

Radio buttons with hidden labels should only be used in contexts that make it clear what the user is selecting. It should be visually tied to a recognizable element, such as selecting a theme preview or picking a color swatch. Always ensure accessible labeling is provided using aria-label or aria- labelledby to support screen readers.
